## Alternative: Supabase Auto-Generated Types

If you're using Supabase's auto-generated types, you can get them by:

### Method 1: Supabase Dashboard
1. Go to your Supabase project
2. Click on "API Docs" in the left sidebar
3. Look for the "Tables and Views" section
4. Copy the TypeScript definitions

### Method 2: Supabase CLI
```bash
# Generate types from your database
npx supabase gen types typescript --project-id YOUR_PROJECT_ID > database.types.ts
```

Then paste the contents here.

## Example Format

If your types look like this:

```typescript
export interface EurekaSet {
  id: number
  title: string
  slug: string
  rarity: number
  style: string
  label: string
  trial: string
  eureka_variants: EurekaVariant[]
}

export interface EurekaVariant {
  id: number
  eureka_set: string
  color: string
  category: string
  image_url: string | null
  default: boolean
}
```

I'll convert them to Swift like this:

```swift
struct EurekaSet: Codable, Identifiable {
    let id: Int
    let title: String
    let slug: String
    let rarity: Int
    let style: String
    let label: String
    let trial: String
    let eurekaVariants: [EurekaVariant]
    
    enum CodingKeys: String, CodingKey {
        case id, title, slug, rarity, style, label, trial
        case eurekaVariants = "eureka_variants"
    }
}

struct EurekaVariant: Codable, Identifiable {
    let id: Int
    let eurekaSet: String
    let color: String
    let category: String
    let imageURL: String?
    let isDefault: Bool
    
    enum CodingKeys: String, CodingKey {
        case id, color, category
        case eurekaSet = "eureka_set"
        case imageURL = "image_url"
        case isDefault = "default"
    }
}
```
